# Arena hotkeys

Open **O → Macros · Hotkeys** in the game. The editor comes to the front of the
journal and other windows. Preset changes and custom bindings are local to this
browser/profile and persist through reloads.

1. Choose **Arena mage** or **Arena warrior** and review the displayed keys.
2. **Add free hotkeys** installs only unoccupied keys; existing bindings are kept.
3. Use **Edit** to rename/rebind or reorder the action steps, then **Save changes**.
   **Cancel changes** leaves the saved binding intact. Duplicate active triggers
   and movement/window keys are refused. Modifier combinations are distinct.
4. **On/Off** disables a binding without deleting it. Search matches names, keys
   and action descriptions. **Back up / restore** opens the existing settings
   export/import panel, including macros.
5. Close the window and return focus to the game to use the key. Form controls
   keep their normal keyboard behavior. On macOS, function keys may require Fn;
   Command/Meta is reserved for the app, and can never trigger a plain-key macro.

Mage defaults: F1 Greater Heal self; F2 Cure self; F3 Energy Bolt; F4 Explosion;
F5 Magic Arrow; F6 Meditation; F7 last target; F8 server Arena menu. Offensive
spells raise the normal target cursor. Self spells use the existing targeted
spell packet; the server decides timing, legality, mana and reagent costs.

Warrior defaults: F1 bandage self; F2 attack last; F3 last weapon; F4 last target;
F5 heal potion; F6 cure potion; F7 refresh potion; F8 Arena menu. Potion hotkeys
search the player's backpack. Arena ranked matches forbid potions; these keys
work in the server's potion-enabled practice AI queue and ordinary shard play.

The Arena menu is a standard server gump and works in ClassicUO too. These Anima
presets do not change ClassicUO's own macro editor or client protocol.
